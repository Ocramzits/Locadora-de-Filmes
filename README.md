# Locadora de Filmes

Este é um projeto de uma locadora de filmes desenvolvido em Python. O objetivo do projeto é usar a biblioteca `PySide6` para criar uma interface gráfica que permita aos usuários gerenciar o catálogo de filmes, realizar locações e devoluções, além de manter um registro dos clientes.

## Funcionalidades

- Adicionar, editar e remover filmes do catálogo.
- Registrar clientes e gerenciar suas informações.
- Realizar locações e devoluções de filmes.
- Visualizar histórico de locações por cliente.
